Engineering Strategy

Android Changes Remain Low-Risk and Localized

1. State Model Enrichment

Upgrade ConvertUiState to include source filename and a cached source Uri. Add a safe retry() method without changing the underlying native conversion call.

Working(sourceName) | Error(sourceName, msg, hasUri)
2. Immediate SingleTop Navigation

Retain immediate navigation from Home to Preview for minimal architectural churn, adding launchSingleTop = true to prevent duplicate back-stack entries during rapid selection.

Preview route rendered immediately for all states
3. Pure Active-State Resolver

Introduce a small pure function resolving the active state between forward and reverse view models, prioritizing non-idle jobs and enabling deterministic unit testing.

resolveActiveState(forwardState, reverseState)
4. Strict Action Shielding

Hide Copy, Share, and Export actions in the top/bottom bars whenever the state is not Done, eliminating accidental export of stale previous results.

Actions visible strictly when state is Done
Zero Core Mutation: JNI bindings, JNI exception mapping, and file system repositories remain completely untouched.
