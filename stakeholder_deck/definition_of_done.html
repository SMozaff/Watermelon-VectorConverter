Acceptance Standard

Definition of Done Is User-Observable

Desktop User Experience Criteria
1
Single Launch Path: Launches straight into a functional workspace after the branded splash.
2
Flexible Input: Select a file via filtered system picker or drag-and-drop onto the workspace.
3
Async Execution: Runs conversion and preview generation without freezing the application window.
4
Output Verification: Inspect side-by-side previews and raw output; execute Copy or Save As.
Android User Experience Criteria
1
Truthful State Feedback: File selection always renders visible Working, Done, or Error screens.
2
Transparent In-Flight Jobs: Displays filename and active status while background conversion completes.
3
Action Shielding: Copy, Share, and Export controls remain hidden until conversion succeeds.
4
Clear Error Recovery: Provides explicit error explanations with Retry and Choose Another File actions.
Release Barrier: No command-line workarounds, unexplained empty preview screens, or stale export actions are permitted.
