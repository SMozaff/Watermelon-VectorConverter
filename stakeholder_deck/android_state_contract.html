Android State Architecture

Android Receives an Explicit Conversion-State Contract

UI State What the User Sees Valid Actions Safeguards & Guarantees
IDLE Neutral guidance: "Choose a file to begin" with clear format requirements. Choose file (returns to Home) Export, Copy, and Share actions are hidden.
WORKING Active filename, accessible progress bar, and "Preparing previews…" status. Back to Home No duplicate picker callbacks; action buttons hidden.
ERROR Filename, specific failure explanation, and confirmation that no output was written. Retry / Choose another Preserves session URI for one-tap retry; no stale export.
DONE Success report, side-by-side previews, output metadata, and raw vector markup. Export / Copy / Share / New Actions execute against verified in-memory result only.
Eliminated Risk: Replaces the collapsed "Nothing to preview yet" bug with predictable, informative UI feedback at every stage.
