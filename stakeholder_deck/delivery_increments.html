Execution Roadmap

Delivery Proceeds in Three Controlled Increments

Increment 01
Desktop Foundation
Key Deliverables:
Refactor desktop state machine to remove placeholder.
Add interactive drag-and-drop & filtered file picker.
Enforce direction selection & input validation.
Review Gate 1: Desktop shell is fully interactive before background conversion is wired.
Increment 02
Core Journeys
Key Deliverables:
Wire desktop async conversion, previews, Copy & Save As.
Upgrade Android view models with source & retry context.
Render Android Working & Error recovery states.
Review Gate 2: Both release blockers are demonstrably resolved on local builds.
Increment 03
Release Candidate
Key Deliverables:
Land unit and state-flow regression tests.
Execute cross-platform manual scenario matrix.
Verify full automated CI workflow suite on GitHub.
Review Gate 3: Release go/no-go signoff backed by zero test regressions and green CI.
Integration Strategy: Land Desktop (PR 1) and Android (PR 2) as separate reviewable pull requests, then validate together as a cohesive release candidate.
